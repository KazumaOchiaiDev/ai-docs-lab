# ai-docs-lab — AI駆動開発時代のドキュメント論

AI 駆動開発では、ボトルネックは実装ではなくドキュメントに移る——という仮説を、**課題設定 → 先行調査 → 仮説 → 実験 → 数値で効果検証**のサイクルで検証する個人研究プロジェクト。

研究対象は「AI にも人間にも機能するドキュメント体系」の設計と、その効果の定量測定。施策（グロッサリ、出典規約、設計書テンプレート、ADR 運用、AI 矛盾検出）を1つずつ導入し、ゴールデン QA ハーネスによる前後比較で効果を測る。規約は Claude Code の機構（rules / skills / subagents / hooks / CI)が守らせる。
