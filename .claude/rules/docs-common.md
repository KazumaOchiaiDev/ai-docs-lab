# 全 Markdown 共通規約（docs-common）v0.1

## 見出しの階層

H1 は文書タイトルとして1文書に1つだけ置く。H2 が主要トピック、H3 がサブトピックで、階層を飛ばさない。

## セクションの書き方

各セクションは、単独で切り出されても意味が通るように自己完結で書く。参照は「前述の方法」のような相対表現ではなく、「出典規約（conventions/citation.md）」のように対象の名前とパスで明示する。

## 出典と正典

技術的主張には一次情報の出典を付ける（様式は conventions/citation.md）。値・決定・意図は正典を参照し、再記述しない（正典の定義は canon.md）。

## 言語と図

本文は日本語で書く。コード・識別子・固有名詞は原文のまま。図は Mermaid で書き、テキストとして Git 管理する。
