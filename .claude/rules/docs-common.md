# 全 Markdown 共通規約（docs-common）v0.1

- 見出し階層を一貫させる: H1 = 文書タイトル（1文書に1つ）、H2 = 主要トピック、H3 = サブトピック。飛び級しない
- 各セクションは、単独で切り出されても意味が通る自己完結の単位にする
- 参照は明示的に書く: 「前述の方法」ではなく「出典規約（conventions/citation.md）の3点セット」のように対象の名前とパスで書く
- 技術的主張には一次情報の出典を付ける（conventions/citation.md）
- 値・決定・意図は正典を参照し、再記述しない（canon.md）
- 本文は日本語。コード・識別子・固有名詞は原文のまま
- 図は Mermaid で書き、テキストとして Git 管理する
