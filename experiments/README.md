# experiments/ — 実験ログ

このプロジェクトの本体。1実験 = 1ファイル（評価設計 v0.1 §3、research/2026-08-25_評価設計_ドキュメント施策の効果測定.md）。実験は記事のネタ元になる（記事との対応は ROADMAP §3）。

## 規則

- ファイル名は連番3桁 + スラッグ: `000_baseline.md`、`001_glossary.md`、…
- テンプレート: `templates/experiment-log.md` を複製し、冒頭の使い方コメントを削除して使う
- 追記型: 過去の記述は書き換えず、日付付きで追記する
- 失敗した施策の記録は成功と同価値。「効かなかった」も結論として残す

## 再開の起点

作業を中断から再開するときは、このディレクトリで**連番が最大の実験ログ**を読めば状況が戻る（ROADMAP §7。この README は含まない）。
