# experiments/ — 実験ログ

このプロジェクトの本体。1実験 = 1ファイル = 1記事（ROADMAP §0）。

## 規則

- ファイル名は連番3桁 + スラッグ: `000_baseline.md`、`001_glossary.md`、…
- テンプレート: `templates/experiment-log.md` を複製して使う
- 追記型: 過去の記述は書き換えず、日付付きで追記する
- 失敗した施策の記録は成功と同価値。「効かなかった」も結論として残す

## 再開の起点

作業を中断から再開するときは、このディレクトリの**最後のファイル**を読めば状況が戻る（ROADMAP §7）。
